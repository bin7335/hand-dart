# 손짓 다트

박람회 부스에서 "어떤 체험을 할지" 골라 주는 손 인식 다트판이에요.
웹캠 앞에서 **손바닥을 보여 주고 → 주먹을 쥐어 다트를 잡고 → 손을 펴면** 다트가 날아가 꽂힌 칸의 체험이 정해져요.

## 실행

1. `start.bat`을 더블클릭해요. (Node.js 필요. 직접 실행: `node serve.mjs`)
2. 브라우저에서 `http://localhost:5173/` 이 열리면 카메라를 고르고 **카메라 켜고 시작하기**를 눌러요.
3. `F`를 눌러 전체 화면으로 바꿔요.

인터넷 없이 동작해요. 손 인식 모델과 라이브러리가 `vendor/mediapipe/`에 들어 있어요.
카메라는 `localhost`(또는 https)에서만 켜지므로 `index.html`을 더블클릭해서 열면 안 돼요.

## 부스 장비

- 노트북 + 외부 대형 모니터 + USB 웹캠(모니터 위에 올리기)
- 관람객은 화면 앞 1-1.5m에 서요. 오른쪽 카메라 화면의 점선 네모 안에 손이 들어오면 돼요.
- 손 뒤가 너무 밝으면(창가, 조명 역광) 인식이 떨어져요.

## 운영 단축키

| 키 | 동작 |
|---|---|
| 스페이스바 | 지금 조준점으로 바로 던지기 (결과 화면에서는 다음 사람으로 넘기기) |
| 마우스 클릭 | 누른 자리로 던지기 |
| S | 설정 |
| F | 전체 화면 |

## 설정 (S)

- **다트판 칸**: 2-8칸, 이름과 색. 기본은 4칸이에요.
- **판 회전 속도**: 0이면 멈춘 판(겨눈 대로), 빠를수록 운이에요.
- **운의 크기**: 다트가 조준점에서 흩어지는 정도예요. 기본은 "반쯤 운".
- **손동작 판정**: 주먹·손바닥을 얼마나 후하게 알아볼지 정해요. 기본은 "후하게".
- **정중앙 자유 선택**: 가운데 별에 꽂히면 원하는 체험을 고르게 해요.
- **결과 보여 주는 시간**, **효과음**, **카메라**.

설정은 이 브라우저에만 저장돼요. 빗나감은 없어요. 판 밖을 겨눠도 가장자리에 꽂혀요.

## 개인정보

카메라 영상은 이 컴퓨터의 브라우저 안에서만 분석하고, 저장하거나 어디로도 보내지 않아요. 외부 요청은 0건이에요(자동 테스트로 확인).

MediaPipe 1.2.2는 사용 통계(영상이 아닌 성능·사용량 수치)를 구글 서버(`odml.pa.googleapis.com`)로 보내려고 해요. 끄는 옵션이 없어서 `index.html`의 CSP(`connect-src 'self'`)로 막아 두었어요. 그래서 개발자 도구 콘솔에 "Refused to connect" 오류가 한 번 찍히는데 정상이에요. CSP 줄을 지우면 통계가 전송되니 지우지 마세요.

## 카메라가 안 켜질 때

- Claude 앱의 미리보기 창에서는 카메라가 막혀 있어요. 크롬이나 엣지에서 `http://localhost:5173/`을 열어요.
- 주소창 왼쪽 아이콘 → 카메라가 "허용"인지 확인해요.
- 줌·카메라 앱처럼 카메라를 쓰는 다른 프로그램을 닫아요.
- USB 웹캠을 꽂은 뒤 설정(S)의 카메라 목록에서 골라요.
- 카메라 없이 시작했다면 오른쪽 위 검은 칸의 **카메라 켜기**를 눌러요.

## 구조

```text
index.html        화면 틀
css/app.css       스타일
js/main.js        게임 흐름(wait → ready → aim → fly → settle → result)과 그리기
js/hand.js        카메라 + 손 인식, 주먹/손바닥 판정
js/settings.js    설정 저장과 설정 창
js/mascot.js      도우미 캐릭터
js/sfx.js         효과음(Web Audio)
vendor/mediapipe/ 손 인식 라이브러리·모델
serve.mjs         로컬 서버
tests/run.mjs     자동 테스트
```

## 테스트

```bash
node tests/run.mjs
```

헤드리스 크롬으로 모델 불러오기, 게임 한 판, 판정 정확도, 대체 입력, 설정 저장, 가짜 카메라 분석을 검사해요.
`IMG_DIR`에 손 사진 폴더(woman_hands.jpg, thumbs_up.jpg, victory.jpg, pointing_up.jpg)를 주면 실제 사진으로 주먹·손바닥 판정도 검사해요.
